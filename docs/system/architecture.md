# 系统架构

独立运维服务读取 Sub2API 管理接口和 PostgreSQL，在自己的状态、数据库模式和媒体目录中保存数据；禁止修改或派生 Sub2API 镜像。

## 组件

| 组件 | 端口 | 职责 |
| --- | --- | --- |
| `operations-console` | `3002 -> 8080` | Fastify、React、自动化、分析、HTTP 审计 |
| `ws-audit-relay` | `3003 -> 8090` | WebSocket 原样转发、持久发件箱、审计投递 |

代码：`routes.ts` 管理接口；`auth.ts` 会话；`automation/` 重置与容量；`analytics.ts` 聚合；`prompt-audit/` 输入审计；`ws-relay/` 实时中继；`shared/contracts.ts` 前后端契约。

## 接口

| 范围 | 作用 |
| --- | --- |
| `/health` | 自动化健康 |
| `/ops/api/auth/*` | 密码、TOTP、OAuth、退出 |
| `/ops/api/bootstrap`、`dashboard` | 管理员、配置、账号、任务、活动 |
| `/ops/api/accounts/:accountKey/analytics` | 日、周、月、周期分析 |
| `/ops/api/prompts*` | 审计列表、详情、会话、图片、清理、解封 |
| `/ops/api/run`、`config` | 手动任务与配置 |
| `/internal/prompts/capture*` | 共享密钥保护的内部采集 |

会话只允许启用中的管理员；令牌保存在加密 `HttpOnly` Cookie，生产使用 `Secure`、`SameSite=Strict`、路径 `/ops`。登录接口限流为 15 分钟 8 次。

## 数据流

周期重置：首次建基线；`reset_at` 明确前移且有用量下降或自然到期佐证后，先持久化订阅清单，再逐项重置并记录进度；重启续跑，同窗口不重复。

容量同步：`周期容量=standardCost/使用率`，按账号配置扣除固定 USD 或周期容量百分比对应的预留金额，再除以 `shareCount`；达到阈值才估算，每个整数使用率桶取首样本，最近 5 桶取中位数，差异不足阈值不写入。账号预留模式、预留值或份数变化时立即使用已有样本重算。

控制台实时数据由 TanStack Query 共享与去重；仪表盘在可见页面中每 60 秒刷新，后台标签页停止轮询。输入健康首次进入时加载默认结果，之后由管理员点击查询、翻页或完成解封操作时刷新，不做周期轮询；筛选控件只编辑草稿，点击查询后才替换当前查询条件。列表 SQL 把时间边界下推到审核日志和 Ops 记录两个来源，并让列表/计数、汇总/趋势各自共享一次去重结果。无搜索词时去重阶段仅读取索引字段，分页后再对当前页补齐正文摘要、媒体数和用户状态，避免 30 天查询物化完整正文。仪表盘触发的账号基础设施查询另有 60 秒服务端缓存，并以单个在途任务合并并发刷新。

用户峰谷限流策略在开启时每 60 秒拉取一次 Sub2API 用户列表，对照当前并发与 RPM 后仅批量写入有差异的活跃用户；调度与容量、重置任务错峰启动。

审计：HTTP 由 Nginx 后台镜像；WebSocket 先写本地发件箱再原样转发。只保存 `input` 最后一项；用户输入关联审核，续跑上下文标记无需审核。文本先脱敏，最多 1,000,000 字符；图片仅收 PNG/JPEG/WebP/GIF `data:`，单张 8 兆、最多 4 张、合计 12 兆，不下载外部网址。会话只保存显式标识的 SHA-256 指纹。

## 持久化与故障

| 数据 | 位置 |
| --- | --- |
| 配置 | `/app/config.json`，格式版本 11 |
| 运行状态 | `/data/state.json`，格式版本 2 |
| 图片 | `/data/prompt-media` |
| 待投递消息 | `/data/outbox` |
| 审计记录 | PostgreSQL `sub2api_ops` |

任一自动化任务最近失败时控制台健康接口返回 `503`，Docker 健康检查仍将 `200/503` 都视为进程可达，避免上游任务降级阻断 WS 中继启动。中继健康接口返回连接数和发件箱用量；控制台不可用时退避重投，发件箱无法写入时关闭连接。具体行为和测试见[规格索引](../specs/README.md)。
