# 功能-004：配置管理

状态：当前实现　范围：配置与管理操作

目标：管理员安全修改自动化和留存配置，保存后立即生效。

## 规则

- 只接受版本 11；账号键、邮箱、目标分组唯一，邮箱转小写。
- 预留不分配属于受管账号，每个账号必须独立选择固定 USD 或百分比模式；固定金额范围为 0～1,000,000 USD，百分比范围为 0～100%。
- 固定分组不可成为目标；风险留存不得短于普通留存；数值必须在校验范围内。
- 保存到 `config.json` 后更新留存、重启计划并写活动；秘密只来自 `.env`。

- 资源监控页允许管理员修改 Sub2API 连接池上限（不低于现有空闲连接数，最多 50）和容器内存（256～768 MiB，且不超过现有内存加 swap 总额）；提交时展示重连影响。
- 独立宿主机服务仅通过权限受限 Unix socket 接受这两个数值和配置修订号；控制台不挂载 Docker socket、不接受命令或任意文件路径。
- 保存并应用先备份，原子更新编排；仅修改内存在线生效，连接池变化重建 Sub2API。保留当前程序版本、环境、配置及业务数据；失败恢复原配置和运行值。
- 应用任务异步执行，显示实际值、配置值和最终结果；同一时刻只允许一个任务，旧修订号拒绝覆盖。任务执行器重启后恢复未完成任务。
- Sub2API 短暂不可用时返回 503 并保留管理员会话，真正的 401/403 才清除会话。

- 每个账号独立保存 `redistributionEnabled`，配置文件字段为 `redistribution_enabled`，未设置时默认关闭。沿用配置版本 11；不改写现有生产配置。

## 场景

| 编号 | 假如 | 当 | 那么 |
| --- | --- | --- | --- |
| 场景-004-01 | 配置有效 | 保存 | 持久化、立即应用并记录活动 |
| 场景-004-02 | 分组归属重复 | 保存 | 整体拒绝 |
| 场景-004-03 | 固定分组成为目标 | 保存 | 拒绝且旧配置不变 |
| 场景-004-04 | 风险留存更短 | 保存 | 拒绝 |
| 场景-004-05 | 不同账号配置不同预留模式和值 | 保存 | 独立持久化并用于各自容量估算 |
| 场景-004-06 | 已登录管理员 | 打开运行参数 | 显示持久配置、实际生效值及最近应用结果 |
| 场景-004-07 | 配置修订号一致且参数有效 | 保存并应用 | 异步执行，内存单独修改不中断连接；连接池变化重建后验证健康 |
| 场景-004-08 | 参数越界、未知字段、修订过期或已有任务 | 提交 | 明确拒绝，现有配置不变 |
| 场景-004-09 | 应用失败或执行器中断 | 恢复 | 回滚原编排与实际运行参数，保留程序版本和受保护文件 |
| 场景-004-10 | Sub2API 正在重建 | 管理员请求 Ops | 返回暂不可用，不强制退出；恢复后仍可查询结果 |
