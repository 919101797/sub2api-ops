# 功能-008：控制台交互与信息层级

状态：当前实现　范围：网页控制台

目标：把运维空间构建成可操作的实时视觉场景，以大胆构图、清晰数据和连续交互共同建立辨识度。

## 规则

- 桌面采用可展开的悬浮导航轨道、场景选择条和宽幅工作画布，默认紧凑导航；页面以大幅标题、错位区域和真实数据排版形成空间层次。移动端采用固定底部导航，并保留非边缘横滑切换和未达阈值回弹。
- 横向表格、表单、弹层、垂直和系统边缘手势不触发页面切换；路由切换回到页面顶部。
- 总览依次呈现资源指标、账号周限、容量分配、家宽链路、任务与近期动态。未知指标显示“—”或等待状态，部分样本汇总明确标注覆盖账号数；不得将未知数据绘制为零。
- 账号支持按名称、邮箱或 ID 搜索，并在同一上下文展开周期和用量分析。活动支持关键词、类别及严重程度筛选。
- 设置分为账号与分组、同步参数、峰谷策略、内容与存储四个面板；切换面板保留草稿。保存前执行表单约束校验，显示未保存状态、保存结果及失败反馈。
- 删除审计数据使用应用内确认弹层；清空全部必须输入“清空全部”。解封明确展示目标用户；取消不发送写请求。提交期间阻止重复操作。
- 保留日蚀、流光、磁流、光隧、极光、潮汐、奔月、星河爆炸、星云潮生九套独立皮肤，和明亮、深色、跟随系统三种模式自由组合。使用原皮肤偏好的存储键 `sub2api-ops-appearance-v1` 和 `{ theme, style }`，直接继续有效的原有选择；未选择皮肤时默认日蚀。
- 每套皮肤同时决定环境画布、页面底色、面板材质、边框反光、强调色和图表颜色；顶部提供直接切换入口，外观弹层显示九套场景预览。切换皮肤仅短暂交接环境画布，不移动正文；场景内部的形变与环境光由同一交互进度驱动。
- 品牌标记采用折带式 S 字母 SVG，以单一连续轮廓、斜切端面和折面反光建立辨识度；动效只作用于反光与微小抬升；登录、桌面、手机和浏览器图标共用源文件，后台与减少动态效果时停止持续运动。
- Tab 与分段选择器共享弹簧指示器，指示器从上一项连续移动到目标项并轻微回弹，快速连续切换可中途转向；各组独立，保持键盘焦点、筛选状态和设置草稿。移动导航拖动跟手，松手后弹簧吸附。
- 极光保留垂幕，潮汐保留海波。沙丘和棱镜删除，替换为奔月、星河爆炸，并新增星云潮生；不保留旧绘制、配色或偏好映射。
- 日蚀之外的八套主题统一采用直接操控：靠近场景主体按距离推进，停住保留当前构图，远离或移出窗口平滑退回；不按时钟自动转场或变色。三套宇宙主题保留完整旅程，通过可逆进度推进奔月、盘古开天与女娲补天。鼠标、触摸和笔输入共用规则；触摸松手或取消后退回。再次激活当前主题可保持展开，再次激活收回，为键盘和窄屏提供同等入口；不添加独立播放按钮。
- 奔月以同一轮真实月球串联古今：开场是银色月光下的古代云海、桂树月宫与写实嫦娥，靠近后人物沿月光升起，飘带与飞行轨迹衔接现代载人火箭的尾焰。云海连续过渡为地球大气层，火箭点火升空、助推器分离，载人飞船接续地月航行，随后近月下降并在月面回望地球。古代神话意象使用分层写实素材，现代航天采用可信的多级火箭、逃逸塔、发动机喷流和舱体结构；不以整枚火箭直接落月，不标记为某次已完成的真实任务。古今交接使用沿飞行方向掠过的分层云幕：镜头跟随嫦娥留下的月光轨迹穿云，火箭从同一视觉锚点显现；月亮在交接时保持位置与大小，不把两个人物主体长时间半透明叠放，不以整屏白幕遮挡。火箭、分离的助推器、芯级和载人上面级使用同一组坐标与尺度，飞船直接来自原火箭舱段；不能退场后另放一艘位置或大小不同的飞船。近月下降采用球面真实投影的地平线，月表沿同一轮廓出现，避免球体消失后切成另一块平面。
- 星河爆炸以唯美、轻盈的开天意境演绎星河诞生：银蓝薄雾与细星尘围绕微光聚拢，远处短暂浮现弱化的人物光影，第一缕珍珠光缓缓舒展，透明云纱与星尘如花瓣般绽开，最终沿同一条曲线流成银河。移除岩石天卵、厚重暗壳、碎石、巨斧特写、冲击圆环和浓烈金褐色曝光；人物只占很小的远景面积，不压住主体。颗粒身份与云纱曲线连续，镜头轻推、缓慢展开，峰值曝光和暖光均受限，不突然爆亮或变成整屏黄褐色。
- 星云潮生演绎女娲补天：青绿云幕后有一条破裂天幕，星光坠落；女娲侧影与托星手掌从云后显现，同一批坠星汇聚为五色石，熔光沿手势变为光丝，依次织合原裂口；新星沿修补路径点亮，人物退入前景云层，留下珍珠色星河。收集、炼石、织补和复明共享粒子身份与位置，缝合前沿跟随光丝抵达顺序，不能先封闭裂口再出现光丝。青绿与珍珠白为主，五色石采用克制的玉、金、赭、银、蓝色。
- 故事的阶段统一驱动画布、页面底色、面板材质、侧栏、弹层、控件、文字、边框、图表与 Logo 的光照和冷暖；主内容不移动、关键文字可读，不白屏或频闪。不显示章节编号、标题、旁白或进度线，故事完全由场景表达。
- 三套场景扩展至全幅画布：地球弧面抬高、近月镜头和月表覆盖更大范围，星河云纱与星云丝流从中右区域延伸到左侧和页面下部；环境光同步覆盖导航与面板，正文保持可读。
- 场景主体附近的指针位置直接决定目标进度，平滑跟随并支持中途反向；流光收束成束，磁流聚合形变，光隧向纵深跃迁，极光垂幕展开，潮汐波前扩散，均同步驱动整页反光。业务按钮、表单、导航、图表交互和弹层不触发场景动作，进入控件后自然退回；三套宇宙场景的推进与回退保留速度惯性，先减速再反向，途中改变目标不瞬间掉头；穿云、分离、进入近月轨道有连续镜头和缓入缓出。明暗和业务页面切换不重置当前进度。后台停止绘制、恢复时不补算离开时间；系统减少动态效果时直接保留静态构图。
- 三套宇宙场景绘制最多 30 帧/秒，画布按设备像素比最高 2 倍绘制、不超过 420 万像素，环境光最多每秒写入 24 次并量化去重。任何阶段与目标位置落稳后停止帧循环；重新交互时只启动一条循环，纹理按需缓存，不逐帧生成。切换或卸载清除曝光、冷暖与进度变量。
- 日蚀遮蔽程度是天体和整页环境光的唯一来源：底色、侧栏、所有面板、弹层、控件、文字、边框、图表和 Logo 同步由日照暖色过渡到全食冷色，返回时恢复。明亮模式从暖白降至暮色灰，深色模式从烟铜降至近黑，正文始终保持可读；不使用整页 brightness 滤镜。光照数值最多每秒写入 24 次，量化去重，不逐帧读取布局；切换皮肤或卸载时清除，减弱动态效果时静态保持，后台暂停。
- 日蚀从明显偏食到完整日冕具有大行程遮蔽，指针进入时向全食聚合、离开后平滑退回，并在静置时缓慢演化；流光为具有空间纵深与指针反馈的能量束；磁流与光隧直接复用 React Bits Ferrofluid 和 Light Tunnel 组件。不得删掉任一皮肤或用单一纯色选项替代。
- 一个页面只挂载一个全屏场景，连续延伸至导航和页面下半部。原有 GPU 场景像素预算 160 万，新宇宙场景预算 420 万，缩略图预算 2.4 万；不逐帧读取布局，不叠加大面积实时背景模糊。后台停止帧循环，恢复时仅启动一个循环；减少动态效果时静态呈现。图形能力不可用时仍须保持全部业务内容可操作。
- 三套宇宙主题保留清晰的月球坑缘、月表颗粒、星云细丝与星点实核；不放大低分辨率噪声代替细节，不以浓雾覆盖轮廓。月球素材保留接近原始分辨率，星云和地形使用预计算高分辨率材质；浏览器只解码和缓存，不同步生成大图。常见 2560×1440 视口至少按 1 倍 CSS 像素绘制，4K/高 DPR 受总像素上限约束。
- 数据不能为视觉效果被伪造、裁切或隐藏；小字号不低于 11px，图表保留真实口径和可访问名称。
- 路由、折叠、筛选、弹层、抽屉、按钮、标签、切换控件和图表均有与其作用相符的反馈：小控件 140–180ms，弹层 180–260ms，空间转换 280–380ms。内容不依赖动画才能出现；减少动态效果时取消位移、连续运动和过渡。
- 文字和数字保持可读，状态同时有文字或图标；保留时间、编号、口径、错误、空状态、重试及安全确认。主标题中文，不添加重复说明或装饰性眉标。只使用项目现有图标库。
- 模态弹层锁定背景滚动、管理焦点、支持 Escape 关闭并在关闭后恢复触发点；主题弹层定位于视口内，支持键盘操作。
- 退出登录成功后立即显示登录页并清除全部私有查询缓存；退出请求失败显示错误且允许重试，不将请求失败伪装为退出成功。
- 查询失败时保留上次成功的数据，明确标注刷新失败并提供重试；首次加载不将未知值显示为零。
- 仪表盘可见时每 60 秒刷新，后台停止轮询且不在回到前台时额外刷新。输入健康首次加载，后续仅在查询、翻页或写操作完成时刷新。查询共享去重。

| 场景-008-26 | 选择任一非日蚀皮肤 | 静置、靠近主体、停住、离开 | 静置不自动推进；靠近推动形变与光照，停住保持，离开沿原进度退回，落稳后无持续帧循环 |

| 场景-008-30 | 2560×1440 桌面或高 DPR 手机 | 选择新宇宙主题 | 桌面画布不低于 CSS 分辨率、手机匹配最高 2 倍 DPR，总像素不超过 420 万；落稳停帧 |

| 场景-008-31 | 非日蚀主题 | 键盘或触屏再次激活当前主题、再激活一次 | 连续展开并保持，再沿当前进度收回；不重建画布或跳回开场 |
| 场景-008-32 | 非日蚀主题主体上触摸或笔输入 | 按住、移动、松手或取消 | 按位置连续推进；松手和取消平滑退回，不阻止业务滚动和移动导航手势 |

| 场景-008-33 | 奔月主题开场 | 靠近、停在古今交接区、继续靠近 | 依次可见嫦娥沿月光穿云、同一锚点出现载人火箭、助推器与芯级实际分离、原舱段继续赴月、球面地平线连续变为月表；各阶段可停留与反向，无位置或尺度跳变 |
| 场景-008-34 | 奔月主题与任一明暗模式 | 在手机与桌面推进或开启减少动态效果 | 月球纹理、人物、火箭和云海分层清楚，主体不遮住业务操作；减少动态效果保留月面静态画面，素材从本地加载并缓存 |

| 场景-008-35 | 奔月正在向前推进 | 指针突然远离再靠近 | 镜头保留瞬时速度，平滑减速、反向再加速；到达目标后停止绘制，后台不累计时间 |
| 场景-008-36 | 古今、火箭赴月或近月转场进行中 | 停在交接前后并正反向查看 | 月亮与主角锚点连续；上面级不在新位置冒出；月表与球面的地平线重合，正文不被转场光幕遮住 |
