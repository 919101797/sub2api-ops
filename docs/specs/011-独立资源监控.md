# 功能-011：独立资源监控

状态：当前实现　范围：宿主机采样、七天留存、ops 历史查询

目标：Sub2API、数据库或 Docker API 无响应时仍留下资源证据，并在 ops 中查看。

## 规则

- 宿主机 systemd 服务每 15 秒直接读取 procfs、cgroup v1 和容器名称元数据，不连接 Docker socket、Sub2API、PostgreSQL 或网络。
- SQLite 独立目录保留最近 7 天；采样服务上限 64 MB、CPU 5%，控制台只读挂载。只保存资源数字、启动编号与容器名称，不保存环境变量、密钥或对话。
- 记录 MemAvailable、swap 使用量和换入换出速率、磁盘读写平均延迟与繁忙比例，以及逐容器总内存、工作集、RSS、缓存、swap、上限和触限计数。
- 首个速率样本及计数回退不显示为零；采样中断超过 45 秒明确告警。历史聚合保留最小可用内存和各容器峰值，断档不连线。
- 资源接口沿用管理员鉴权；数据库不存在明确报未安装，不伪造健康数据。页面最多返回 480 个时间桶。
- 2 GB 部署为业务容器设置内存与 swap 预算，Go/Node 运行时提前回收；HTTP 与 WebSocket 按功能-012执行可配置的用户上限，超限明确拒绝，不裁剪对话。WebSocket 总积压按功能-007限制。

## 场景

| 编号 | 假如 | 当 | 那么 |
| --- | --- | --- | --- |
| 场景-011-01 | 上游服务与 Docker API 不可用 | 独立采样运行 | 宿主机及现存 cgroup 数据继续入库 |
| 场景-011-02 | 连续两次计数可用 | 相隔 15 秒 | 正确计算 swap 速率和磁盘延迟；首次或计数回退为未知 |
| 场景-011-03 | 数据超过七天 | 新样本入库 | 过期样本删除，七天内样本保留 |
| 场景-011-04 | 管理员查询历史 | 存在短暂尖峰及断档 | 尖峰保留，超过 45 秒的采样断档明确显示 |
| 场景-011-05 | 采样未安装、已停止或访问者未登录 | 请求资源接口 | 分别显示未安装、过期提示或拒绝访问 |
