# 功能-006：提示词审计

状态：当前实现　范围：输入健康

目标：外置采集最后一项 Responses 输入，形成受控、可关联、可查询和可清理的审核证据。

## 规则

- 内部采集需共享密钥；只取 `input` 最后一项，区分用户、助手、开发者和工具上下文。
- 用户输入关联审核；续跑上下文标记无需审核。保存前脱敏；文本上限 1,000,000 字符。
- 图片仅收类型真实一致的 PNG/JPEG/WebP/GIF `data:`；单张 8 兆、最多 4 张、合计 12 兆，不下载网址。
- 会话来源顺序为 `X-Session-Id`、`X-Conversation-ID`、`prompt_cache_key`，只存 SHA-256。
- HTTP 按请求编号关联；WebSocket 按连接、序号和时间关联；留存从消息创建时间计算。
- 管理员清理不修改 Sub2API 原审核日志，并记录清理边界和活动。
- 管理员可配置单次审计正文上限为 1～16 MiB；HTTP 镜像和 WebSocket 消息在读取正文前检查声明大小，超过上限或大小未知时直接跳过，不解析、不排队、不落库，且不影响主请求。

## 场景

| 编号 | 假如 | 当 | 那么 |
| --- | --- | --- | --- |
| 场景-006-01 | 多轮输入最后为用户 | 采集 | 只存最后用户文本、合规图片并关联审核 |
| 场景-006-02 | 最后为续跑上下文 | 采集 | 保存实际内容并标记无需审核 |
| 场景-006-03 | 含凭据、超长文本或伪造图片 | 持久化 | 脱敏、显式截断或拒绝图片 |
| 场景-006-04 | 提供显式会话标识 | 多次采集 | 以指纹形成时间线 |
| 场景-006-05 | 记录到期或管理员确认清理 | 清理 | 删除完整记录和图片，保留原审核日志 |
| 场景-006-06 | 单次审计正文超过管理员配置上限或未声明大小 | 采集 | 在读取正文前返回成功并跳过审计，主请求不受影响 |
| 场景-006-07 | 管理员修改状态、用户、分组、搜索或精确时间条件 | 尚未点击查询 | 保留当前结果，不发起新列表请求；点击查询后一次性提交全部条件 |
| 场景-006-08 | 查询 24 小时、7 天、30 天或精确时间范围 | 读取列表、总数、汇总和趋势 | 时间条件先进入两个来源表的索引扫描；列表与总数、汇总与趋势分别共用一次去重结果 |
| 场景-006-09 | 查询 30 天大数据量审计记录 | 搜索词为空 | 去重、计数与分页阶段不读取完整正文、媒体和用户状态；仅对当前页记录补齐展示字段 |
