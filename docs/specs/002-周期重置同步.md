# 功能-002：周期重置同步

状态：当前实现　范围：额度自动化

目标：确认 OpenAI 进入新周期后，每个目标订阅只重置一次；重启可续跑。

## 规则

- 首次只建基线；`reset_at` 明确前移且有用量下降或旧窗口到期佐证才触发。
- 执行前持久化窗口和订阅清单，逐项记录进度；同窗口不重复，同类任务不并发。
- 停用账号和固定排除分组不参与。

## 场景

| 编号 | 假如 | 当 | 那么 |
| --- | --- | --- | --- |
| 场景-002-01 | 无历史观测 | 首次运行 | 保存基线，不重置 |
| 场景-002-02 | 新窗口且有佐证 | 运行 | 先存事件，再逐项重置并完成 |
| 场景-002-03 | 时间仅抖动或无佐证 | 运行 | 不创建事件、不重置 |
| 场景-002-04 | 事件仅完成部分订阅 | 重启再运行 | 只继续剩余项 |
